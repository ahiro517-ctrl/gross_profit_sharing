# 粗利見える化ツール セットアップマニュアル(非エンジニア向け)

このマニュアルは、プログラミング経験がない方でも一人でセットアップを完了できるように書いています。
上から順番に進めてください。**所要時間は約30〜40分**です(PCの再起動などは不要)。

つまずいたら、最後の「**8. よくあるエラーと対処法**」を見てください。だいたいそこに載っています。

---

## 全体の流れ

```
① 道具の準備(Node.js と clasp をPCに入れる)     … 10分
② Google との接続(ログインとAPIの有効化)        … 5分
③ ツール一式のダウンロード                        … 5分
④ スプレッドシートの作成とプログラムの転送        … 5分
⑤ スプレッドシート側の初期化(シート自動生成)    … 10分
⑥ メンバー登録と共有                              … 5分
⑦ 動作確認                                        … 5分
```

「clasp(クラスプ)」は、PCに置いたプログラムファイルを Google スプレッドシートへ
転送するための Google 公式の道具です。**①〜④はセットアップする人(あなた)だけ**が行えばOKで、
他のメンバーは何もインストールする必要はありません。

---

## 0. 準備するもの

- [ ] 会社の Google アカウント(スプレッドシートが使えるもの)
- [ ] 自分のPC(Windows または Mac)
- [ ] このリポジトリ(GitHubページ)のURL

## 1. 道具の準備(Node.js と clasp)

### 1-1. ターミナル(黒い画面)を開く

これから「コマンド」という文字の命令をPCに打ち込みます。そのための画面を開きます。

- **Windows**:スタートボタンを押して「**PowerShell**」と入力 → 「Windows PowerShell」をクリック
- **Mac**:画面右上の虫めがね(Spotlight)で「**ターミナル**」と入力 → 「ターミナル.app」をクリック

> 💡 コマンドは1行ずつコピーして貼り付け、**Enterキーで実行**します。
> 貼り付けは Windows なら右クリック、Mac なら Cmd+V です。

### 1-2. Node.js をインストールする

1. ブラウザで https://nodejs.org/ja を開く
2. 緑色の「**LTS**」と書かれたボタンからインストーラーをダウンロード
3. ダウンロードしたファイルをダブルクリックし、**すべて「次へ」(Next)のまま**インストール
4. インストールが終わったら、**ターミナルをいったん閉じて、開き直す**(重要!)
5. 確認のため、次のコマンドを実行:

   ```
   node -v
   ```

   `v22.12.0` のようなバージョン番号が出ればOKです。
   「認識されません」「command not found」と出る場合は、ターミナルの開き直し忘れです。

### 1-3. clasp をインストールする

ターミナルで次を実行します:

```
npm install -g @google/clasp@2.4.2
```

- 1〜2分かかります。警告(WARN)が黄色で出ても気にしなくてOKです
- **Mac で「permission denied」と出た場合**は、先頭に `sudo ` を付けて実行し、PCのパスワードを入力:

  ```
  sudo npm install -g @google/clasp@2.4.2
  ```

確認のため:

```
clasp -v
```

`2.4.2` と出ればOKです。

> ⚠️ **Windows で「このシステムではスクリプトの実行が無効になっているため…」という赤いエラーが出た場合**
> 次のコマンドを1回実行してから、やり直してください(「Y」を聞かれたら Y + Enter):
>
> ```
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

## 2. Google との接続

### 2-1. clasp で Google にログインする

ターミナルで:

```
clasp login
```

- ブラウザが自動で開き、Google のログイン画面が出ます
- **会社の Google アカウント**を選択してください(個人アカウントと間違えないように!)
- 「clasp – The Apps Script CLI が Google アカウントへのアクセスをリクエストしています」
  という画面が出たら「**許可**」をクリック
- ターミナルに `Authorization successful.` と出れば成功です

### 2-2. Apps Script API を有効にする(忘れると必ずエラーになります)

1. ブラウザで https://script.google.com/home/usersettings を開く
2. 「**Google Apps Script API**」のスイッチを「**オン**」にする

これだけです。オンにした直後は反映に1〜2分かかることがあります。

## 3. ツール一式のダウンロード

1. ブラウザでこのリポジトリの GitHub ページを開く
2. 緑色の「**Code**」ボタン → 「**Download ZIP**」をクリック
3. ダウンロードした ZIP ファイルを右クリック → 「すべて展開」(Mac はダブルクリック)
4. 展開してできたフォルダ(`gross_profit_sharing-main` のような名前)を、
   **デスクトップなど分かりやすい場所**に置く

次に、ターミナルで**そのフォルダの中に移動**します。`cd ` (cdと半角スペース)と入力したあと、
フォルダをターミナル画面に**ドラッグ&ドロップ**して Enter を押すのが簡単です:

```
cd (ここにフォルダをドラッグ&ドロップ)
```

正しい場所に入れたか、フォルダの中身を表示して確認します:

- Windows の場合: `dir` と入力して Enter
- Mac の場合: `ls` と入力して Enter

`src` や `README.md` が表示されれば、正しい場所にいます。

> ⚠️ **「二重フォルダ」に注意(Windowsで特に多いつまずきポイント)**
> Windowsの「すべて展開」は、ZIPと同じ名前のフォルダを**もう1段**作ります。
> `dir` で `src` が見えず、**同じ長い名前のフォルダがもう1つ見える**場合は、
> その中にもう1階層入ってください:
>
> ```
> cd .\gross_profit_sharing-main
> ```
>
> (フォルダ名は実際に表示されたものに合わせてください。`cd .\gross` まで打って
> **Tabキー**を押すと残りが自動補完されます)
> もう一度 `dir` して、`src` が見えてから次の章へ進みます。
> **`src` が見えない場所で手順4を実行すると、`ENOENT: ...\src\.clasp.json` という
> エラーになります。**

> ⚠️ **以降のコマンドはすべて「`src` が見えるこのフォルダの中」で実行します。**
> ターミナルを閉じてしまったら、開き直して再度 `cd` でフォルダに入ってください。

## 4. スプレッドシートの作成とプログラムの転送

### 4-1. スプレッドシートを新規作成する(プログラム付きで)

ターミナルで:

```
clasp create --type sheets --title "粗利見える化ツール" --rootDir src
```

成功すると、次のような2行が表示されます:

```
Created new Google Sheet: https://drive.google.com/open?id=xxxxx
Created new Google Sheets Add-on script: https://script.google.com/d/yyyyy/edit
```

これで、あなたの Google ドライブの一番上(マイドライブ)に
「**粗利見える化ツール**」というスプレッドシートが作られました。
同時に、フォルダの中に `.clasp.json` という設定ファイルが自動で作られます
(これが「転送先のスプレッドシートはどれか」の記録です。次の `clasp push` が
このファイルを使うため、**このコマンドが成功していないと 4-2 は必ず失敗します**)。

> 💡 すでにあるスプレッドシートを使いたい場合は、この章の代わりに
> 最後の「**付録A:既存のスプレッドシートに入れる場合**」を見てください。

> ⚠️ `User has not enabled the Apps Script API` というエラーが出たら、
> 手順 2-2 を忘れています。設定をオンにして1分待ってからやり直してください。
>
> ⚠️ このコマンドは**1回だけ**実行してください。2回実行すると、ドライブに
> スプレッドシートが2つできてしまいます(その場合は、タブが「シート1」だけの
> 空っぽの方をドライブから削除すればOKです)。

### 4-2. プログラムを転送する

ターミナルで:

```
clasp push
```

- `Manifest file has been updated. Do you want to push and overwrite?` と聞かれたら
  「**y**」と入力して Enter
- 最後に `Pushed 16 files.` のように出れば成功です

> ⚠️ **`No valid ....clasp.json project file. You may need to "create" or "clone" a project first.` と出た場合**
> 手順 4-1(`clasp create`)が実行されていない(または途中で失敗した)サインです。
> 4-1 に戻ってコマンドを実行し、`Created new Google Sheet:` の表示を確認してから、
> もう一度 `clasp push` してください。
> (※ `(node:12345) DeprecationWarning: The punycode module is deprecated...` という
> 黄色っぽい警告は無視してかまいません。エラーではありません)

これで転送は完了です。**今後プログラムが更新されたときも、新しいZIPを展開して
`cd` でフォルダに入り、`clasp push` を実行するだけで反映されます**(シートのデータは消えません)。

## 5. スプレッドシート側の初期化

### 5-1. スプレッドシートを開く

Google ドライブ(https://drive.google.com)を開き、「**粗利見える化ツール**」をダブルクリックして開きます。

開いて数秒待つと、メニューバー(「ファイル 編集 表示…」の並び)の右端に
「**粗利ツール**」というメニューが現れます。

> 出てこない場合は、ブラウザでページを再読み込み(F5 / Cmd+R)してください。

### 5-2. 初期セットアップを実行する(承認画面が出ます)

1. メニューから「**粗利ツール > 管理者 > 初期セットアップ**」をクリック
2. 「**承認が必要です**」というダイアログが出るので「**OK**(続行)」をクリック
3. Google アカウントの選択画面 → **会社のアカウント**を選択
4. ここで「**このアプリは Google で確認されていません**」という警告画面が出ます。
   **これは異常ではありません**(自社で作ったプログラムなので Google の審査を受けていない、という意味です)。
   - 左下の「**詳細**」(Advanced)をクリック
   - 「**粗利見える化ツール(安全ではないページ)に移動**」をクリック
5. 「粗利見える化ツールが Google アカウントへのアクセスをリクエストしています」→「**許可**」をクリック
6. **承認しただけでは実行されていないので、もう一度**
   「粗利ツール > 管理者 > 初期セットアップ」をクリック
7. 画面右下に「初期セットアップが完了しました」と出れば成功です

シートの下のタブに、次が自動で作られています:

| タブ | 役割 |
|---|---|
| 設定_マスタ | 等級・単価・目標などの設定(管理者のみ編集可) |
| 設定_メンバー | メンバー名簿(次の手順で入力します) |
| kintone貼付 | kintoneのCSVを貼り付ける場所 |
| 案件データ / 案件入力 / 分配入力 | データ本体(直接編集しません) |
| V_個人 / V_ユニット / V_経営 | 見るための画面 |

> 💡 「集計」「監査ログ」という非表示のタブもありますが、触る必要はありません。
> また、初期セットアップを実行したあなたが自動的に「管理者」として登録されています。

## 6. メンバー登録と共有

### 6-1. メンバーを登録する

「**設定_メンバー**」タブを開き、2行目から1人1行で入力します:

| 列 | 入力する内容 | 例 |
|---|---|---|
| 氏名 | 表示に使う名前(社内で呼ぶ名前) | 山田太郎 |
| メール | **会社のGoogleアカウントのメール**(これで本人を判別します。正確に!) | yamada@example.com |
| ユニット | 所属ユニット名(表記を全員でそろえる) | ユニット1 |
| 現等級 | b / a1 / a2 / l1 のどれか(プルダウン) | a1 |
| 年次 | 入社からの年数(b等級の目標額の判定に使用) | 2 |
| 評価対象 | チェックを入れる(新卒3ヶ月・中途1年未満は外す) | ☑ |
| 評価開始日 | 評価対象になる日(参考情報。空欄でも可) | 2026/07/01 |
| ユニット長 | ユニット長だけチェック(個人目標が500万になります) | ☐ |

### 6-2. もう一度、初期セットアップを実行する

メンバーを入れ終わったら、再度「**粗利ツール > 管理者 > 初期セットアップ**」を実行します。
(V_個人・V_ユニットの選択プルダウンに、いま登録したメンバー・ユニットが反映されます)

### 6-3. メンバーに共有する

1. 画面右上の「**共有**」ボタンをクリック
2. メンバー全員のメールアドレスを追加し、権限を「**編集者**」にして送信

> ⚠️ 「閲覧者」ではメニューからの入力ができません。必ず「編集者」にしてください。
> 入力シートには保護がかかっており、通常の操作はすべて「粗利ツール」メニュー経由で行うため、
> 編集者でも勝手にデータを壊しにくい作りになっています。

## 7. 動作確認(kintone取込を試す)

1. kintone から案件の CSV を書き出す
2. Google ドライブに CSV をアップロードする(ドライブ画面にドラッグ&ドロップ)
3. アップロードした CSV を**右クリック → アプリで開く → Google スプレッドシート**
   (こうすると文字化けせずに開けます)
4. 開いたシートで **全選択(Ctrl+A / Cmd+A)→ コピー**
5. 「粗利見える化ツール」の「**kintone貼付**」タブを開き、A1セルをクリックして**貼り付け**
6. メニュー「**粗利ツール > kintone取込**」をクリック
7. 右下に「kintone取込 完了: 新規○件 / 更新○件」と出て、
   「案件データ」タブに案件が並んでいれば**セットアップ完了です!** 🎉

最後に「**粗利ツール > ビュー更新**」を実行し、V_個人タブの B1 セルで自分の名前を
選ぶと、個人ビューが表示されることも確認してください。

## 8. よくあるエラーと対処法

| 症状 | 原因と対処 |
|---|---|
| `node` や `clasp` が「認識されません / command not found」 | インストール後にターミナルを開き直していない。**ターミナルを閉じて開き直す** |
| Windowsで「スクリプトの実行が無効になっているため…」 | 手順1-3の `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を実行 |
| `User has not enabled the Apps Script API` | 手順2-2の設定がオフ。https://script.google.com/home/usersettings でオンにして1分待つ |
| `clasp create` の最後に `ENOENT: no such file or directory, open '...\src\.clasp.json'` | 今いるフォルダに `src` がない(ZIP展開の「二重フォルダ」が原因。手順3の注意参照)。**スプレッドシート自体は作成済み**なので、`create` は再実行せず「**付録D**」の手順で復旧する |
| `clasp push` で `No valid ....clasp.json project file. You may need to "create" or "clone" a project first.` | `clasp create`(手順4-1)を実行していないか、別のフォルダで実行した。手順4-1を実行してから push し直す。すでに4-1済みの場合は、4-1を実行したフォルダに `cd` で入り直す。4-1で上の `ENOENT` エラーが出ていた場合は「**付録D**」へ |
| `DeprecationWarning: The punycode module is deprecated...` という警告 | エラーではありません。無視してOK(その下に別のエラーが出ていないかだけ確認) |
| `clasp push` で `Push failed` / 403 | `clasp login` のアカウントが違う。`clasp logout` → `clasp login` で会社アカウントに入り直す |
| メニュー「粗利ツール」が出ない | ページを再読み込み(F5)。それでも出なければ `clasp push` が成功しているか確認 |
| 「このアプリは Google で確認されていません」 | 異常ではありません。手順5-2の通り「詳細」→「(安全ではないページ)に移動」→「許可」 |
| 初期セットアップで「この操作は管理者のみ実行できます」 | 設定_マスタの「管理者メール」にあなたのメールが入っていない。管理者に追加してもらうか、設定_マスタのT列に自分のメールを追記(初回実行者は自動登録されます) |
| kintone取込で「必須ヘッダーが見つからない」 | 貼り付けたデータの1行目がヘッダー(「案件ID」「案件名」…)になっているか確認。CSVの2行目以降から貼ってしまっているケースが大半 |
| 貼り付けた日本語が文字化けしている | CSVを直接開かず、手順7の「ドライブにアップロード→アプリで開く→Googleスプレッドシート」の方法で開く |
| メンバーがフォーム送信時に承認画面が出る | 正常です。各メンバーも初回だけ手順5-2と同じ承認が必要です(2回目からは出ません) |

## 付録A:既存のスプレッドシートに入れる場合

新規作成(手順4-1)ではなく、すでにあるスプレッドシートを使いたい場合:

1. そのスプレッドシートを開き、メニュー「**拡張機能 > Apps Script**」をクリック
2. 開いた画面の左側の歯車アイコン「**プロジェクトの設定**」をクリック
3. 「**スクリプト ID**」の「コピー」を押す
4. PCのフォルダにある `.clasp.json.example` というファイルをコピーして、
   ファイル名を `.clasp.json` に変える(メモ帳/テキストエディットで編集できます)
5. 中身の `ここにコンテナバインドスクリプトのIDを貼る` の部分を、コピーしたIDに置き換えて保存:

   ```json
   {
     "scriptId": "コピーしたスクリプトID",
     "rootDir": "src"
   }
   ```

6. あとは手順4-2(`clasp push`)から同じです

> 💡 Windowsでファイル名を変えるとき「拡張子を変更すると…」と警告が出たら「はい」でOKです。
> ファイル名が `.clasp.json.txt` になってしまう場合は、エクスプローラーの「表示」タブで
> 「ファイル名拡張子」にチェックを入れてから変更してください。

## 付録B:プログラムを最新版に更新するとき

1. GitHub から新しい ZIP をダウンロードして展開
2. 展開したフォルダに、いま使っている `.clasp.json` をコピーして入れる
   (`clasp create` で作った場合、元のフォルダの中にあります)
3. ターミナルで `cd` でそのフォルダに入り、`clasp push` を実行

スプレッドシートのデータ(案件・分配・メンバー設定)はそのまま残ります。
更新後は念のため「粗利ツール > 管理者 > 初期セットアップ」を1回実行してください
(列やシートが追加された場合に反映されます)。

## 付録C:2人目以降の「管理者」を増やすとき

「設定_マスタ」タブの「■管理者」(T列)に、その人のメールアドレスを追記するだけです。
管理者は「確定値修正」「半期締め」などの管理メニューが使えるようになります。

## 付録D:`clasp create` は成功したのに `.clasp.json` が作られなかったとき

手順4-1で `Created new Google Sheet:` の2行は出たのに、最後に
`ENOENT: ...\src\.clasp.json` と出た場合の復旧手順です。
Google 側のスプレッドシートとプログラムの入れ物は**すでに作成されています**。
足りないのは「転送先の記録ファイル(.clasp.json)」だけなので、それを手で作ります。

1. まず手順3の「二重フォルダ」の注意を見て、`dir`(Mac は `ls`)で **`src` が見える
   フォルダに移動**する
2. 手順4-1のときに表示された2行目のURLから、**スクリプトID**を控える:

   ```
   Created new Google Sheets Add-on script: https://script.google.com/d/【この部分がスクリプトID】/edit
   ```

   (画面をスクロールすれば残っています。消してしまった場合は、Googleドライブで
   「粗利見える化ツール」を開き、「拡張機能 > Apps Script > 歯車(プロジェクトの設定)」
   からも同じIDをコピーできます)
3. 次の1行の `ここにスクリプトID` を置き換えて実行する(Windows PowerShell):

   ```
   Set-Content -Path .clasp.json -Value '{"scriptId":"ここにスクリプトID","rootDir":"src"}'
   ```

   Mac の場合:

   ```
   echo '{"scriptId":"ここにスクリプトID","rootDir":"src"}' > .clasp.json
   ```

4. `clasp push` を実行(手順4-2)。`Pushed 16 files.` と出れば復旧完了です。
   ドライブに既にある「粗利見える化ツール」がそのまま転送先になります
