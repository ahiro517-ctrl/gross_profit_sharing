# 粗利見える化ツール 利用ガイド(入力操作とビューの見方)

セットアップが終わった人向けの、日常の使い方ガイドです。
「**1. 15分お試しツアー**」を最初にやると、入力からビューまで一通り体験できて、
ツールが正しく動いているかの確認にもなります。

> 操作はすべてスプレッドシート上部のメニュー「**粗利ツール**」から行います。
> セルに直接入力するのは「設定_メンバー」(管理者)と「kintone貼付」だけです。
> それ以外のシートを直接編集しようとすると警告が出ます(「キャンセル」を押してください)。

---

## 1. 15分お試しツアー(動作確認を兼ねた体験コース)

実際に1案件を最初から最後まで動かしてみます。**数字どおりになれば正常動作です**。
テストで作ったデータの消し方は最後の「**7. テストデータの後片付け**」にあります。

### 準備

- kintone取込が済んでいること(セットアップマニュアル手順7)
- 「設定_メンバー」に自分を含む2〜3人が登録されていること

以下、登場人物を **自分(メイン担当)**、**Aさん**、**Bさん** とします。
「案件データ」タブを見て、フェーズが失注でない案件をどれか1つ選んでください(以下「テスト案件」)。

### ステップ1:案件登録(見積入力)

1. メニュー「粗利ツール > **案件登録(見積入力)**」→ 右側にフォームが開く
   (初回は承認画面が出ます。セットアップマニュアル手順5-2と同じ流れで許可)
2. 案件の欄にテスト案件のIDか名前を入力すると候補が出るので選択
3. メイン担当が自動で入る(kintoneの案件所有者から。違っていれば変更)
4. 見積_売上 **1000000**、見積_原価 **200000** と入力 → 粗利が **800000** と自動計算される
5. 「登録する」をクリック

**✅ 確認**:「案件入力」タブにテスト案件の行ができ、入力ステータスが「確定待ち(進行中)」、
請求月・半期が自動で入っている。

### ステップ2:現場分配(Aさんが現場に2.5日入った)

1. 「粗利ツール > **現場分配を入力**」
2. テスト案件を選択、メンバーは **Aさん**、ポジション **ディレクター**、日数 **2.5**
3. フォームに金額 **135,000円** と表示される(1日5万×2日+半日3.5万×1回)
4. 「現場分配を記録する」をクリック
   - Aさんの等級が a2 未満なら「⚠等級条件を満たしていません」と出ますが、
     **警告だけで記録はされます**(仕様どおり)

**✅ 確認**:「案件入力」タブの「現場稼働合計」が **135,000**、
「制作原資_予測」が **665,000**(=80万−13.5万)になっている。

### ステップ3:制作分配(Bさんに30%)

1. 「粗利ツール > **制作分配を入力**」
2. テスト案件を選択 → 「メイン担当:○○」と表示される
3. メンバー **Bさん**、% に **30** → 下に「メイン担当の取り分: 70%」と表示される
4. 「制作分配を登録する」をクリック

**✅ 確認**:「分配入力」タブに、
- Bさん:制作30% → 予測額 **199,500**(=665,000×30%)
- 自分(メイン担当):制作70%の行が**自動で**でき、予測額 **465,500**
- 確定額はどちらも**空欄**(案件がまだ確定していないため)

### ステップ4:ビューで見る

1. 「粗利ツール > **ビュー更新**」を実行
2. 「V_個人」タブを開き、B1セルのプルダウンで **Bさん** を選択

**✅ 確認**:半期サマリの「予測粗利」に 199,500 が入っている(請求月が当半期の場合)。
「自分の案件一覧」にテスト案件が役割「制作」で出ている。
請求月が次の半期なら「次半期以降の計上分」枠に出ます(これも正常です)。

### ステップ5:確定値入力(案件終了)

1. 「粗利ツール > **確定値入力**」
2. テスト案件を選択 → 見積時の値が参考表示される
3. 確定_売上 **900000**、確定_原価 **150000**(粗利 **750000**)
4. 確認ダイアログ(再編集できません)→ OK で登録

**✅ 確認**:「案件入力」タブで、
- ステータスが「**確定済**」、見積確定差額 **-50,000**(=75万−80万)
- 制作原資_確定 **615,000**(=75万−13.5万)
- 「分配入力」でBさんの確定額 **184,500**(=615,000×30%)、メイン担当 **430,500**
- もう一度「確定値入力」で同じ案件を選ぼうとしても**一覧に出てこない**(再編集防止)

### ステップ6:取消も試す

1. 「粗利ツール > **分配取消**」→ 一覧からBさんの制作行にチェック → 取消
2. あなたは管理者なのでそのまま取消が成功します
   (確定済み案件の取消は管理者限定です。一般メンバーが同じ操作をすると
   「確定済み案件の分配取消は管理者のみ可能です」と止まります)
3. 「分配入力」タブを見ると、Bさんの行は消えずに「無効」列にチェックが付き、
   メイン担当の自動行が**100%に戻っている**ことが確認できます

ここまで動けば、すべての機能が正常です。🎉

## 2. 画面の全体像(どのタブが何か)

| タブ | 何をする場所か | 触ってよい? |
|---|---|---|
| V_個人 / V_ユニット / V_経営 | **見る**場所 | B1のプルダウンだけ操作OK |
| kintone貼付 | CSVを貼る場所 | 貼り付けOK |
| 設定_メンバー / 設定_マスタ | 名簿と設定 | 管理者のみ |
| 案件データ / 案件入力 / 分配入力 | データ本体 | **直接編集しない**(メニューから操作) |

**メニュー「粗利ツール」がすべての入口です:**

```
粗利ツール
├ kintone取込            … CSVを案件データに反映
├ 案件登録(見積入力)   … キックオフ時(メイン担当)
├ 確定値入力             … 案件終了時(メイン担当)
├ 現場分配を入力         … 現場に入ったら(本人)
├ 制作分配を入力         … メンバー招集時(メイン担当)
├ まとめ分配             … 子案件が多いとき(メイン担当)
├ 分配取消               … 入力ミスの取消
├ ビュー更新 / 再計算
└ 管理者                 … 確定値修正・半期締めなど
```

## 3. 入力操作ガイド(いつ・誰が・何を)

### 3-1. kintone取込(誰でも・週1回程度)

1. kintoneからCSVを書き出す
2. GoogleドライブにCSVをアップロード → 右クリック → アプリで開く → Googleスプレッドシート
3. 開いたら全選択(Ctrl+A)してコピー
4. 「kintone貼付」タブのA1に貼り付け(前回の貼り付けが残っていてもそのまま上書き貼り付けでOK)
5. 「粗利ツール > kintone取込」

案件IDをキーに更新されるので、**何度実行しても二重になりません**。
列の並び順が変わっていても、ヘッダー名で判別するので問題ありません。

### 3-2. 案件登録(メイン担当・キックオフ時)

- 案件はkintoneから取り込んだものから選びます。失注・登録済み・運用開始月より前の案件は
  出ません(フォーム上部に「選択できる案件: ○件」と除外理由が表示されます)
- **見積の売上・原価・粗利**を入力します(原価は外注費などの**社外原価のみ**。
  社員の稼働は原価に入れません)
- 粗利は自動計算されますが手で直せます
- 「請求月上書き」は通常**空欄**。年間一括3月請求のような例外だけ `2027/03` の形式で入力
- 見積値は登録後に変更できません(確定値は別で入力するので上書きされる心配なし)

### 3-3. 現場分配(本人・現場に入ったら)

- **自分で入力する**のがルールです(自分の粗利を自分でつける)
- ポジションと日数(0.5刻み)を入れると金額が即表示されます
- **稼働メモ(任意)**:同じ案件に複数回現場へ入る場合に「6/14-15 設営」「7/1 本番」のように
  どの稼働かを書いておけます(1回分をまとめて日数2日と入力してOK。分ける必要はありません)
- 単価と等級は**入力した時点の値で固定**されます。あとで昇格・単価改定があっても変わりません
- 案件登録前の案件にも入力できます(金額が固定なので問題ありません)
- ポジションの等級条件(ディレクターはa2以上など)を満たさない場合は警告が出ますが、
  記録はされます。気になる場合はユニット長に確認を

### 3-4. 制作分配(メイン担当・メンバー招集時)

- kintone見積書の業務分担に対応するイメージで、メンバーと%を設定します
- 案件を選ぶと「設定済みの分配:佐藤 30%、鈴木 20%」のように**現在の分配状況が表示**されます。
  二重登録を選択時点で気づけます
- **メイン担当の%は入力しません**。残り(100−他メンバー合計)が自動で付きます
- 他メンバーの合計が100%を超えるとエラーで止まります
- 金額は「その案件の制作原資 × %」で自動計算され、原資が動けば(確定値入力で)追従します
- **%を変えたいとき**は、その人の行を「分配取消」してから入れ直します

### 3-5. まとめ分配(メイン担当・子案件が多いプロジェクト)

シナハロのように1プロジェクトが30件の案件に分かれているときの時短機能です。

- 「親案件で絞り込み」を選ぶと、その親に属する案件が**自動で全部チェック**されます(外すのも自由)
- 親案件が設定されていないグループは、一覧から手でチェックすればOK
- メンバーと%を**1回だけ**入力すると、チェックした全案件に同じ%の分配行が作られます
- 計上は**案件ごと**です(各案件の原資×%、各案件の請求月)。請求月がバラバラでも正しく計上されます
- あとから特定の子案件だけ調整したいときは、その案件の行だけ取消→個別入力
- 子案件が後から増えたら、**新しい案件にだけ**もう一度まとめ分配を実行
- **現場分配はまとめ分配できません**。代表案件を1つ決めて通常の現場分配で入力してください

### 3-6. 確定値入力(メイン担当・案件終了時)

- 精算見積書・請求書ベースの確定値(売上・原価・粗利)を入力します
- ⚠ **一度入れると自分では直せません**。修正は管理者の「確定値修正」だけです。
  数字が固まってから入力してください
- 評価に使われるのは**この確定値から計算された分配額だけ**です

### 3-7. 分配取消(入力ミスのとき)

- 取消は「論理削除」です。行は残りますが、集計から除外されます
- 絞り込み欄に案件名や自分の名前を入れると探しやすいです
- 確定済み案件の分配取消は管理者のみできます
- メイン担当の自動行(残り%)は取消できません(他メンバーの%で自動的に決まるため)

### 3-8. 管理者メニュー

| メニュー | 用途 |
|---|---|
| 初期セットアップ | 最初の1回+プログラム更新後 |
| 保護を再設定 | シート保護が外れてしまったとき |
| 確定値修正 | 確定値の入力ミスを直す(履歴が監査ログに残ります) |
| 請求月上書き修正 | 登録後に請求月の例外を設定・解除する |
| 半期締め | 半期評価の確定後に実行。その半期のデータが変更不可になります |
| ビュー自動更新を有効化/無効化 | 約1時間ごとに全ビューを自動更新するかを切り替え |

**運用開始月の設定**:`設定_マスタ` の「■設定」にある「**運用開始月**」(例: `2026/01`)を入れると、
それより請求月が前の案件は「やること」リストと各フォームの選択肢から除外されます。
過去のkintone案件を消す必要はありません(集計対象にもなりません ※入力をしなければ)。

## 4. ビューの見方

すべてのビューは「**粗利ツール > ビュー更新**」で最新になります。
B1のプルダウンを変えたときは自動で更新されます。
管理者が「**管理者 > ビュー自動更新を有効化**」を実行すると、**約1時間ごとに自動更新**されます
(各ビュー2行目に最終更新日時が表示されます)。

**色と太字の意味(各ビューの2行目にも凡例があります):**

| 見た目 | 意味 |
|---|---|
| 青い帯+太字 | セクションの見出し(「今半期サマリ」など) |
| グレーの帯+太字 | 表の列名 |
| 赤い背景の行 | 警告あり/目標未達(見込を足しても目標に届かない) |

**半期の表記**:「2026前期(2026/07〜2026/12)」のように必ず期間つきで表示されます。
前期=7〜12月、後期=1〜6月です。このシートは**半期で作り直さず、ずっと継ぎ足しで**使います。
半期が終わったら管理者が「半期締め」を実行して過去データを凍結し、ビューは自動的に
新しい半期に切り替わります。

### 4-1. まず数字の意味(全ビュー共通)

| 用語 | 意味 |
|---|---|
| **確定** | 確定した分配額の合計。**評価に使われるのはこれ**。現場分は入力した時点で確定、制作分は案件の確定値入力後に確定します |
| **見込(予測)** | 確定+進行中案件の予測分配額。「このままいけば半期でいくらになるか」 |
| **目標** | 等級×年次で決まる半期目標(ユニット長は個人目標500万) |
| **目標差額** | 見込−目標。**マイナスなら、このままでは届かない**ということ |
| **達成率** | 確定÷目標。半期の終盤に向けて100%を目指す数字 |

**大事なルール**:すべての数字は案件の**請求月**(=納品予定日_終の月)の半期に計上されます。
今月稼働しても、請求が次の半期なら次の半期の数字です(個人ビューの「次半期以降の計上分」に出ます)。

### 4-2. V_個人(自分のページ)

B1で自分の名前を選ぶと、上から6つの枠が表示されます:

1. **あなたのやること** — 自分が対応すべき入力のリスト。ここが「—」なら入力漏れなし
   - 「案件登録」:あなたが案件所有者なのに見積が未登録の案件
   - 「確定値入力」:請求月を過ぎたのに確定値が入っていない案件
2. **半期サマリ** — 目標に対する現在地。まずここだけ見ればOK
3. **月別** — 請求月ベースの月ごとの確定/見込/件数。**忙しさの偏り**が見えます
4. **今半期の案件別内訳** — どの案件でいくら粗利を出したかの積み上げ。見込額の大きい順に
   構成比(その案件が自分の半期見込の何%か)つきで表示されます。
   分配入力シートを見渡さなくても、ここで案件ごとの内訳を確認できます
5. **次半期以降の計上分** — 請求月が先の案件はここに分かれて表示されます
6. **自分の案件一覧(全期間)** — 関わっている案件すべて(役割:メイン/現場/制作)。
   同じ親案件の案件はまとまって表示され、小計行が付きます。
   **行が赤い**のは警告あり(赤字など)。警告列に理由が書いてあります

> 💡 スプレッドシートを開いたとき、B1には自動で自分の名前が入ります(初回のみ)。

### 4-3. V_ユニット(ユニット長のページ)

B1でユニットを選ぶと:

1. **ユニットサマリ** — ユニット目標(=メンバー目標の合計)に対する確定/見込
2. **メンバー別** — 全員の横並び表。**赤い行=見込を足しても目標に届かないメンバー**。
   ここがアサイン相談のトリガーです。ユニット長自身も同じ表に載ります
3. **未入力・要対応一覧** — メンバー別の入力漏れ。研修時間などでの声かけ材料に

### 4-4. V_経営

選択操作なしで、上から:

1. **半期サマリ** — 全社とユニットの並列比較
2. **月別推移** — 全社・ユニット別の確定/見込
3. **メンバー別の表** — ユニットごとに縦に並びます(全員分を1ページで見られます)

## 5. 警告の意味と対処(案件入力の「警告」列/ビューの赤い行)

警告は**入力を止めません**。状況を見えるようにするためのものです。

| 警告 | 意味 | 対処 |
|---|---|---|
| 赤字(予測/確定原資マイナス) | 現場分配の合計が粗利を超えた | 仕様どおりマイナスのまま制作メンバーに按分されます。案件の値付け・体制の見直し材料に |
| 制作%合計≠100 | 分配バランスが崩れている | 通常は自動で100%になります。出た場合は分配取消→入れ直し |
| 他メンバー%が100超 | シートの直接編集などで起きた異常 | 管理者に連絡 |
| 等級条件違反の現場分配あり | 等級が足りないポジションで稼働 | 意図的ならそのままでOK(評価時の参考情報) |
| 所有者複数記載(1行目を採用) | kintoneの案件所有者が複数人 | kintone側で1名に直すのが推奨 |
| メンバーマスタと照合不可 | 所有者のメールが名簿にない | 共有アカウント等。案件登録時にメイン担当を手で選べば問題なし |
| 請求月未確定 | kintoneの納品予定日_終が空 | kintone側で日付を入れて再取込、または請求月上書きを使う |

## 6. よくある質問

**Q. 入力を間違えた**
A. 分配(現場/制作)→「分配取消」して入れ直し。見積値・確定値 → 管理者の「確定値修正」へ。

**Q. 請求が来期にずれた/年間一括請求になった**
A. kintoneの納品予定日_終を直して再取込(自動追従)、または管理者メニュー「請求月上書き修正」。

**Q. 数字が古い気がする**
A. 「粗利ツール > ビュー更新」を実行してください。入力のたびに再計算されますが、ビューは更新操作が必要です。

**Q. 担当案件なのに「あなたのやること」に出ない**
A. kintoneの案件所有者のメールと「設定_メンバー」のメールが一致しているか確認してください。

**Q. 現場で稼働したのに半期サマリに入っていない**
A. その案件の請求月が来期の可能性があります。V_個人の「来期以降の計上分」を見てください。

**Q. メンバーの%を後から増やしたい(例:30%→40%)**
A. その人の制作行を「分配取消」→ 40%で入れ直し。メイン担当の残り%は自動で追従します。

**Q. 失注になった案件はどうなる?**
A. 取込時に反映され、新規の登録・分配の選択肢から消えます。入力済みの分配がある場合は分配取消で整理してください。

**Q. 分配入力にある「自動行」とは?**
A. メイン担当の取り分(100−他メンバー%合計)を表す行で、ツールが自動で作って常に最新に保ちます。
直接編集・取消はできません。他メンバーの%を変えると自動で追従します。分配IDが「AUTO-案件ID」になっています。

**Q. 設定_マスタは編集していい?**
A. **値の変更はOK、構造の変更はNG**です。単価・目標額・マッピングのヘッダー名・設定値は自由に変更できます
(変更後に「再計算」を実行)。ポジションの行追加もOK。一方、**等級の名前(b/a1/a2/l1)**はメンバーマスタ・
目標表・ポジションの最低等級とつながっているため、変えるなら全箇所をそろえる必要があります。
順位の数字は等級の上下判定に使うので並びどおりに。**列の位置・セクション見出し行・ヘッダー行は動かさないでください**(読み取り位置が固定のため)。

**Q. 設定_メンバーの「年次」は中途社員にも必要?「評価開始日」は?**
A. 年次は**b等級の目標額の判定だけ**に使います(b以外は空欄でOK)。評価開始日は計算には使わない
運用管理用のメモです(いつから評価対象かを記録しておく欄)。

**Q. kintone貼付から行を消して取込したのに、案件データから消えない**
A. 仕様です。取込は「追加と更新」だけで**削除はしません**(一部だけ貼り付けたときにデータが
消える事故を防ぐため)。過去案件を見せたくない場合は削除ではなく「運用開始月」を設定してください。

**Q. 案件データを並べ替えていい?**
A. 取込のたびに**請求月の新しい順に自動で並び直します**。手で並べ替えても壊れませんが、次の取込で戻ります。

**Q. 確定値入力の「確定」とは?その後の分配はできる?**
A. 確定値=その案件の売上・原価・粗利の確定(請求書ベース)です。**確定後も現場分配・制作分配の追加はできます**
(請求確定後に分配を整える運用を想定)。確定済み案件の分配の「取消」だけは管理者限定です。

## 7. テストデータの後片付け(運用開始前のみ)

お試しツアーで作ったデータは、**運用開始前なら**管理者が直接消してかまいません:

1. 「分配入力」タブでテスト案件の行(メイン担当の自動行・取消済みの行も含めて全部)を選び、
   右クリック → 行を削除(保護の警告が出たら、そのまま続行)
2. 「案件入力」タブのテスト案件の行も同様に削除
3. 「粗利ツール > 再計算」→「ビュー更新」を実行

「案件データ」の行はkintone由来の正データなので消さなくてOKです。
**運用開始後は行削除はせず**、必ず「分配取消」と管理者メニューを使ってください
(監査ログに履歴が残る方法だけを使うのがルールです)。
